# NETWORKWALKS-ZOE-B083-WK2-PM2-NETWORK-SCANNING-WITH-ZENMAP
# Project Overview
This project demonstrates the use of Nmap (Network Mapper) to discover devices, identify open ports, and gather basic information about hosts on a network. The project was carried out in a controlled cybersecurity lab environment.

# Objectives
1. Install and configure Nmap.
2. Identify active hosts on the network.
3. Scan a target system for open ports.
4. Identify running services and their versions.
5. Understand basic Nmap scanning techniques.
6. Document and analyze the scan results.
